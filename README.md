# Skills

Colección personal de habilidades reutilizables para agentes de IA.

## Catálogo

- [goHighLevel / GHL Growth Website Builder](goHighLevel/ghl-growth-website-builder/SKILL.md): estrategia, construcción, captación y validación de sitios en GoHighLevel (Running X / Ronin X).

## Uso

La carpeta de cada skill contiene `SKILL.md` y material de apoyo. Lee ese archivo antes de crear o mejorar un sitio.

Para usarla en Claude Code: copia `goHighLevel/ghl-growth-website-builder` en `.claude/skills/` de tu proyecto. Para otras herramientas, proporciona `SKILL.md` como instrucciones y sus referencias cuando sean pertinentes.

> Las URLs, credenciales, correos y datos de clientes no deben copiarse de un proyecto a otro.
