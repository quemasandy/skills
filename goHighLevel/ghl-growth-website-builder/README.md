# GHL Growth Website Builder

Skill portable para crear sitios web y landing pages en GoHighLevel / Running X / Ronin X, basada en las lecciones del proyecto A10Z.

## Uso
1. Lee [SKILL.md](SKILL.md).
2. Completa los datos del cliente con [PROMPT_MAESTRO.md](PROMPT_MAESTRO.md).
3. Consulta [lecciones A10Z](references/lecciones-a10z.md), [operación GHL](references/operacion-ghl.md) y [QA](references/qa.md).
4. Construye una identidad nueva por cliente, entrega HTML personalizado y prueba realmente calendario, formulario y DNS.

La skill no copia automáticamente el estilo Ink de A10Z. Evita secretos, credenciales y datos personales en archivos públicos.

## Próximas extensiones
Generador parametrizado de HTML, presets visuales, screenshots de ejemplo y pruebas automatizadas pueden añadirse en `scripts/`, `assets/` y `examples/`.
